## 👋 Introduction

**Congolese Developers** brings together the people who build technology in and for the
Democratic Republic of Congo — wherever they live today.

Whether you write your first `print("Hello, World!")` in Kinshasa, train machine-learning
models in Lubumbashi, maintain cloud infrastructure in Goma, or build mobile apps from the
diaspora, this is your home on GitHub.

This repository is the **central hub** of the community. It is where you:

| | |
|:--:|:--|
| 🙋 | **Introduce yourself** and join the community |
| 💡 | **Propose** new open-source projects |
| 🐛 | **Report** bugs and suggest improvements |
| 📚 | **Find** learning resources and guides |
| 🤝 | **Meet** contributors and maintainers |

## 🙋 How to Join

Joining takes less than two minutes and is completely free.

1. **Create a GitHub account** if you don't have one at [github.com/signup](https://github.com/signup).
2. **Open a "Join the Community" issue** from the [issue templates](../../issues/new/choose)
   and fill in the short form (GitHub username, languages, interests — province and
   experience level are optional).
3. **Introduce yourself** in the *Introductions* category of [Discussions](../../discussions).
4. **Star ⭐ and watch 👀** this repository to follow announcements.

A community administrator will welcome you and, if you wish, invite you to the GitHub
organization.

> 🌱 **New to programming or Git?** Start with our [Getting Started guide](docs/getting-started.md).
> Every expert was once a beginner.

## 🤝 How to Contribute

Every contribution counts — code, documentation, translations, design, bug reports and
answers to other members' questions.

```bash
# 1. Fork this repository on GitHub, then clone your fork
git clone https://github.com/<your-username>/community.git
cd community

# 2. Create a branch for your change
git checkout -b docs/improve-faq

# 3. Make your changes, then commit with a conventional message
git add .
git commit -m "docs: add question about mentorship to the FAQ"

# 4. Push and open a Pull Request
git push origin docs/improve-faq
```

We use [Conventional Commits](https://www.conventionalcommits.org/):

| Type | Use it for |
|:--|:--|
| `feat` | A new feature |
| `fix` | A bug fix |
| `docs` | Documentation only |
| `refactor` | Code restructuring without behavior change |
| `test` | Adding or updating tests |
| `chore` | Maintenance tasks |

📘 **Read the full, beginner-friendly guide in [CONTRIBUTING.md](CONTRIBUTING.md).**

## 📜 Community Guidelines

We are committed to a welcoming, respectful and harassment-free community.

- 💬 Be kind, patient and constructive.
- 🌍 Welcome everyone — whatever their province, stack, experience or background.
- 🔍 Search existing issues and discussions before opening a new one.
- 🧠 Ask questions freely; there are no "stupid" questions.
- 🚫 Harassment, discrimination, insults and intimidation are never tolerated.

Read the [Code of Conduct](CODE_OF_CONDUCT.md) and the
[Community Guidelines](docs/community-guidelines.md).

## 🏛️ Governance

Congolese Developers is run openly, with clearly documented roles and transparent
decision-making.

```text
                 ┌──────────────┐
                 │   Founder    │  Vision · coordination · appoints first maintainers
                 └──────┬───────┘
                        │
           ┌────────────┴────────────┐
           │ Organization Admins     │  GitHub settings · permissions · repositories
           └────────────┬────────────┘
                        │
           ┌────────────┴────────────┐
           │ Project Maintainers     │  Review PRs · triage issues · lead projects
           └────────────┬────────────┘
                        │
           ┌────────────┴────────────┐
           │ Contributors            │  Code · docs · bug reports · discussions
           └────────────┬────────────┘
                        │
           ┌────────────┴────────────┐
           │ Community Members       │  Ideas · discussions · helping newcomers
           └─────────────────────────┘
```

Roles, responsibilities and the decision process are described in
[GOVERNANCE.md](GOVERNANCE.md).

## ❓ Frequently Asked Questions

<details>
<summary><b>Who can join Congolese Developers?</b></summary>

<br>

Anyone interested in technology in the DRC: developers, students, researchers, designers,
engineers and enthusiasts — in the country or abroad. Friends of the community from other
countries are welcome too.
</details>

<details>
<summary><b>Do I need to be an experienced developer?</b></summary>

<br>

No. Beginners are especially welcome. Start with the [Getting Started guide](docs/getting-started.md).
</details>

<details>
<summary><b>Is it free?</b></summary>

<br>

Yes. Membership and all community resources are free.
</details>

<details>
<summary><b>Can I write in French?</b></summary>

<br>

Yes. English is the primary language of the documentation so the community stays accessible
internationally, but you can open issues and discussions in French. A French overview is
available in [docs/fr](docs/fr/README.md).
</details>

<br>

Open a [Project Proposal](../../issues/new/choose) issue. The process is described in
[docs/projects.md](docs/projects.md).
